此文档记录着 JSTG 内部使用的一些有特殊含义专有词汇。

`弹幕引擎` - 指 [simple 的弹幕引擎模板](https://www.ccw.site/detail/66b599236d94eb6335e33779) 。JSTG 中的许多词汇和术语都继承自弹幕引擎。  

`ASSERTS:` - 这个词出现在注释中，代表此处断言了一件事情。
`MAGIC:` - 这个词出现在注释中，代表此处使用了一些不寻常的神奇写法，奇技淫巧。比如 as unknown as xxx 之类的。
`MAYDO:` - 这个词出现在注释中，含义类似于`TODO:`，表示今后可能会在这里加什么东西。但比`TODO:`的优先级更低，是可做可不做的内容。

`Entity` - 版面上所有能撞到自机造成伤害的东西。  
`Danmaku` - 弹幕，一颗弹幕。  
`LaserBeam` - 直线激光。  
`CurveLaser` - 曲线激光。  
`Erase` - 消弹。消弹会产生消弹特效，可以产生得分道具等。有些弹幕免疫消弹。  
`Enemy` - 版面上所有能被玩家攻击并击破的东西。包括小怪（杂鱼）和 boss 。  
`Hurt` - 受伤。注意是自己受到伤害（被动）才能用这个词，自己去让别人受伤（主动）不能用这个词。  

所有弹幕的id都采用全小写。  
`bacteria` - 菌弹。别名葡萄弹。  
`bacillus` - 杆菌弹。就是那个大肠杆菌。  
`yinyang` - 中号阴阳玉弹幕。  
`bigyinyang` - 大号阴阳玉弹幕。  
`yinYangOrb` - 阴阳玉敌人。  
*注：陰陽玉 onmyou dama / onmyou gyoku，我不懂日文……*  

`Destroy` - 摧毁对象。摧毁后的对象不能再使用。这是继承自 PIXI 的生命周期管理方案。  

`Player` - 自机。  
`Avatar` - 自机在版面上的主要外观，也就是俗称“像素绘”的那个东西，虽然 JSTG 中这个东西完全不“像素”。  
`Hitbox` - 判定范围。  
`Bomb` - 自机符卡。  
`Drone` - 子机。
`Spellcard` - 敌方符卡。  
`PlayerBullet` - 能够攻击敌人的那些子弹。  

所有英文单词的复数形式都直接加个`s`，比如`Enemy`的复数是`Enemys`，`Data`的复数也是`Datas`。别跟我提什么词法、变形啥的，我写的是`js/ts`，不是`en`，我用不着遵循英语的词法。直接加`s`我看着比较舒服。
