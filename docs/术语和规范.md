
# 关于 commit message

标有“`鸡毛蒜皮`”的更改是那些非常不重要的小更改。几乎任何情况下，都不需要关注这些更改。通常是加个空格、改个错别字、微调个数值之类的。*（真是个通俗易懂的词汇啊）*

`[game]` 类别的更改表示既不是新特性，也不是重构的关于游戏内容的更改。例如调整伤害和血量数值、调整贴图外观、缩短动画时长等等。在 JSTG 早期的很长一段时间内，这类更改强行划入了 `[refactor]` 类别中。

# 关于 JSTG 中的名称和词汇

JSTG 中，所有时间单位均为“帧”，即 1/60 秒。

所有名称都应该采用驼峰命名法。所有可以直接使用的东西（例如变量、常量和函数）都应该使用小驼峰命名，类名、异步函数、生成器等不能直接使用的名称则使用大驼峰。这是为了提醒编程者在使用大驼峰名称时应当加上`await`等特殊处理。`gen`是个例外，`gen`常出现在脚本中，用于给符卡或弹幕定义回调生成器函数，为了便于书写而使用小写字母开头。

以下划线`_`开头的东西是内部使用的，不建议在外部使用。这样的东西通常会在注释中标注`@internal`。

以下 JSTG 内部使用的一些有特殊含义专有词汇。这些词汇不应该用于表示其他含义。例如，不要用`yinYangOrb`指代灵梦的子机。  

`弹幕引擎` - 指 [simple 的弹幕引擎模板](https://www.ccw.site/detail/66b599236d94eb6335e33779) 。JSTG 中的许多词汇和术语都继承自弹幕引擎。不要对这个词望文生义！  

`ASSERTS:` - 这个词出现在注释中，代表此处断言了一件事情。  
`MAGIC:` - 这个词出现在注释中，代表此处使用了一些不寻常的神奇写法，奇技淫巧。比如 as unknown as xxx 之类的。  
`RNG:` - 这个词出现在注释中，表示这里用随机数发生器生成了一些随机数，这种随机数是可以稳定复现的，并且会改变随机数发生器的状态。`RNG: EFF`表示此处是一个纯粹的特效，无关游戏内容。  
`MRAND:` - 这个词出现在注释中，表示这里用`Math.random()`或类似的东西生成了一些不可复现的随机数。  
`MAYDO:` - 这个词出现在注释中，含义类似于`TODO:`，表示今后可能会在这里加什么东西。但比`TODO:`的优先级更低，是可做可不做的内容。  
`TODOC:` - 这个词出现在注释中，含义类似于`TODO:`，表示这里的注释文档暂且留空或者有待完善。  

`Entity` - 版面上一个会动的东西。可以是对`pixi.Sprite`的一种简单的封装，自带几个关于运动的方法。  
`Danmaku` - 版面上所有能撞到自机造成伤害的东西。可能是一颗弹幕，也可能是一个小怪（带体术）。常缩写为`dan`。  
`LaserBeam` - 直线激光。  
`CurveLaser` - 曲线激光。  
`Erase` - 消弹。消弹会产生消弹特效，可以产生得分道具等。有些弹幕免疫消弹。  
`Enemy` - 版面上所有能被玩家攻击并击破的东西。包括小怪（杂鱼）和 boss 身上的护盾。注意 boss 本体不算，那只是个视觉效果。  
`Hurt` - 受伤。注意是自己受到伤害（被动）才能用这个词，自己去让别人受伤（主动）不能用这个词。  
`Gun` - 发弹点。理论上讲，这是个专门用来发射弹幕的实体。很直白的名字。其实任何实体都能用来发弹，Gun 只是方便。  

所有弹幕的id都采用全小写。  
参考资料：[thbwiki 上的术语对照表](https://thwiki.cc/游戏攻略/STG术语对照#弹幕种类)  
弹幕引擎中已有的名称，尽可能保留下来；弹幕引擎中没有的名称，尽可能采用英文社区中已有的常用表述。（但也不能全部照搬，因为现有的英文表述也很混乱……）  
`popcorn` - 菌弹。别名葡萄弹。  
`darkpill` - 杆菌弹。就是那个大肠杆菌。  
`yinyang` - 中号阴阳玉弹幕。  
`bigyinyang` - 大号阴阳玉弹幕。  
`yinYangOrb` - 阴阳玉敌人。  
*注：陰陽玉 onmyou dama / onmyou gyoku，我不懂日文……*  

`Destroy` - 摧毁对象。摧毁后的对象不能再使用。这是继承自 PIXI 的生命周期管理方案。  
`Kill` - 杀死对象。通常是消除弹幕、击破敌人等。杀死后的镀锡不能再安全地使用。  
原则上，`Destroy`不应该有副作用，而`Kill`通常有副作用，例如生成消弹特效等。  

`Player` - 自机。  
`Avatar` - 自机在版面上的主要外观，也就是俗称“像素绘”的那个东西，虽然 JSTG 中这个东西完全不“像素”。  
`Hitbox` - 判定范围。  
`Bomb` - 自机符卡。  
`Drone` - 子机。  
`Spellcard` - 敌方符卡。注意，跟字面意思不同，非符也算`Spellcard`。*（NaN是数字，null是对象，棍母是母亲，非符是符，这个世界他妈的到底怎么了）*  
`PlayerBullet` - 能够攻击敌人的那些子弹。  
`CharFigure` - 角色立绘。可以简写为`figure`。  

所有英文单词的复数形式都直接加个`s`，比如`Enemy`的复数是`Enemys`，`Data`的复数也是`Datas`。别跟我提什么词法、变形啥的，我写的是`js/ts`，不是`en`，我用不着遵循英语的词法。直接加`s`我看着比较舒服。（除了本来就以`s`结尾的词，这种需要考虑一下……比如`Boss`的复数暂且采用`Bosses`。）

`TS` - 即`time stamp`，时间戳，用一个数字表示并记录时间轴上的某一个特定时刻。比如`birthClockTS`可能是这个东西刚刷新出来时记录下的`clock`值，是它的“生日”。

`foo` - 带有`foo`的名称是临时使用的名称，换言之是留给以后再起名的占位符。这样的名称通常以`foo_`开头。
`spde` - 带有`spde`的名称是从弹幕引擎里原样照抄来的东西，因为没有合适的替代名称，或者想要尽可能精确保留原意，所以使用`spde`来表示。这样的名称通常以`spde_`开头。
